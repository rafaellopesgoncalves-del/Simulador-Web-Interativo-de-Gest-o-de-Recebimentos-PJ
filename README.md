# 🏦 Simulador Web Interativo de Gestão de Recebimentos PJ

Este repositório contém o código-fonte de um simulador web interativo voltado para a gestão de pagamentos, recebimentos corporativos e controle de fluxo de caixa para Pessoa Jurídica (PJ). O projeto une conceitos de *Cash Management* do mercado financeiro à lógica de desenvolvimento front-end dinâmico.

---

## 🎯 Objetivo do Projeto

O objetivo principal desta aplicação é transformar uma interface estática de gestão financeira em uma experiência interativa, funcional e dinâmica para o usuário. 

A aplicação simula o ecossistema de liquidação de recebíveis e controle de caixa empresarial, atacando três desafios centrais:
* **Interatividade em Tempo Real:** Capturar ações do usuário para atualizar tabelas, saldos e resumos operacionais dinamicamente, sem a necessidade de recarregar a página.
* **Persistência Local de Dados:** Garantir que lançamentos e registros simulados permaneçam salvos no navegador, contornando a ausência temporária de um servidor backend.
* **Simulação de Fluxos Corporativos:** Replicar a dinâmica de liquidação de pagamentos e recebimentos PJ em um ambiente representativo das rotinas de *Cash Management* e integração com ERPs.

---

## 🛠️ Tecnologias Utilizadas

A construção da aplicação priorizou o uso de tecnologias fundamentais de desenvolvimento web, assegurando o domínio dos conceitos base de front-end:

* **HTML5:** Estruturação semântica da interface, tabelas e formulários de entrada de dados financeiros.
* **CSS3:** Estilização responsiva, organização de layout e sinalização visual de entradas/saídas de caixa.
* **JavaScript (ES6+):** Lógica da aplicação, manipulação dinâmica do DOM, escuta de eventos (`addEventListener`) e validação de dados.
* **Web Storage API (LocalStorage):** Leitura e gravação de dados em formato JSON para garantir a persistência local das operações.
* **Git & GitHub:** Controle de versão e estruturação do portfólio digital.

---

## 💡 O que foi Aprendido com a Experiência

A elaboração desta solução técnica permitiu consolidar aprendizados práticos essenciais para o desenvolvimento de software:

* **Manipulação do DOM e Eventos:** Domínio na criação, alteração e remoção dinâmica de elementos na tela com base na navegação do usuário.
* **Gestão de Estado no Front-End:** Compreensão prática de como manter a sincronia entre os dados exibidos na interface e as informações salvas no `LocalStorage`.
* **Estruturação de Dados com JSON:** Prática na organização de objetos e listas para simular retornos de APIs de pagamentos.
* **Ponte entre Negócio e Tecnologia:** Capacidade de traduzir regras complexas de produtos financeiros e gestão PJ em algoritmos e funcionalidades funcionais de software.
